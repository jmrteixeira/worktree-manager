# Code Of Conduct

Worktree Manager is a developer tool community. We want it to be practical, respectful, and welcoming to people with different backgrounds, experience levels, languages, and workflows.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections gracefully.
- Keep discussions focused on the work and the user impact.
- Give clear technical feedback without personal attacks.
- Respect privacy when sharing logs, repository paths, screenshots, or diagnostics.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Dismissing safety concerns around destructive Git operations.
- Repeatedly derailing issues or pull requests.
- Spam or promotional content unrelated to the project.

## Enforcement

Maintainers may edit or remove comments, close issues, reject pull requests, or block participants when behavior harms the community or project.

If you need to report a conduct issue, contact a maintainer privately. Include links, screenshots, and context when possible.
